# ADR-003：数据库是 Agent-工具策略真相源

> 状态：已接受
> 负责人：项目维护者
> 决策日期：2026-06-09
> 适用版本：V1
> 最后更新：2026-06-09
> 阅读顺序：03-03

## 背景

管理员需要为 Agent 绑定 MCP 工具，并为每个工具配置是否需要用户授权。运行时必须区分未绑定、无需授权和需要授权。

## 决策

- 使用 `agent_tool_policy` 保存 Agent-工具绑定和 `authMode`。
- 记录存在表示已绑定，记录不存在表示未绑定。
- V1 每次运行时授权判断直接查询数据库。
- 管理员按 Agent 整份保存，未提交的旧工具视为解绑。
- V1 不为工具策略增加 Redis 缓存。

## 后果

- 数据库是唯一配置真相源，不存在缓存一致性问题。
- 数据库不可用时必须默认拒绝，不能进入用户授权页面。
- 运行时数据库压力需要通过容量测试评估。
- 未来可以引入 Redis 加速，但数据库仍保持真相源。
