# ADR-002：V1 只支持当前对话授权

> 状态：已接受
> 负责人：项目维护者
> 决策日期：2026-06-09
> 适用版本：V1
> 最后更新：2026-06-09
> 阅读顺序：03-02

## 背景

长期或跨对话授权会引入有效期、撤销、授权列表和更复杂的数据隔离。V1 需要先验证人在回路授权链路。

## 决策

- 用户授权只对当前 `tokenId` 和目标 `toolId` 生效。
- Redis Key 固定为 `authz:{tokenId}:{toolId}`。
- 授权页面只展示“允许本次对话调用该工具”。
- 业务后端在对话结束或删除时触发授权清理。
- V1 暂不提供 7 天、30 天或 Agent 级授权，相关能力在未来演进中设计和开发。

## 后果

- 授权边界清晰，不会自动扩展到同一 Agent 的其他对话。
- Redis 丢失时默认未授权，用户需要重新确认。
- 对话结束清理成为必要的生命周期事件。
- 跨对话授权暂只在未来演进文档中设计，不进入 V1 验收。
