## 与前 6 页的承接

第 4 页聚焦资源访问方式：

```text
Agent 不能直连机机 API 或数据资源

```

第 5 页聚焦凭证委托方式：

```text

```

第 6 页聚焦精细化委托控制：

```text
最终权限 = 用户权限 ∩ Agent操作权限 ∩ 任务被授予的权限
高危工具需要人工确认
```

第 7 页聚焦 A2A 协作链路：

```text
用户任务先经过 Agent 网关（人机）
AgentA 调 AgentB 必须经过 Agent 网关（机机）
Agent Owner 审批授权后才能发起 A2A 调用

AgentB 调目标工具必须经过 MCP 网关
策略中心判断协作链路是否允许访问目标工具

```

本页不是重新讲单 Agent 调工具，也不是展开策略中心详细方案，而是把多 Agent 协作时的权限传递和审计链路讲清楚：人机入口收口、机机协作受控、链路审计可还原。
