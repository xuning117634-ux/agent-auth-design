把下面的提示词复制到图片/PPT 生成工具中，并上传两张参考图。

- 参考图 1：Agent 代理模式复杂示意图，只用于提取两类调用方式和风险含义，不要复刻复杂业务链路。
- 参考图 2：智能体模式示意图，只借鉴中心 Agent 的视觉风格和风险警示表达，不要保留发散到设备、文件、大模型密钥等元素。

目标是生成一页 16:9 中文企业汇报 PPT 图：完整页面结构、纯白背景、颜色只进入明确框框/卡片/标签/节点内。页面需要和第一页“传统业务模式”保持一致风格，用最简单的链路说明智能体模式下 `Agent` 代人调用应用，权限边界出现安全真空。

副标题：

- 画布背景必须是纯白色 `#FFFFFF`。
- 除节点、标签、风险卡片、结论带等“框框”内部之外，其余所有区域都必须保持纯白色。

这是一页用来和第一页“传统业务模式”形成对比的页面。主图不要做成复杂发散图，而是做成清晰横向链路：人把目标交给 Agent，Agent 再调用应用，应用后面连接 API 和数据库。

## 核心图示

主图必须是横向链路：

```text
用户 -> Agent -> 应用 -> API -> 数据库
```

要求：

- `用户`、`应用`、`API`、`数据库` 的视觉元素可以参考第一页材料，保持同一套蓝紫科技风。
- `Agent` 放在 `用户` 和 `应用` 中间，用蓝紫渐变圆角矩形或卡片表示，内部可以写 `自主推理 / 代为调用`。
- `应用 -> API -> 数据库` 保持清晰单线链路，不要画成多资源发散。
- `Agent -> 应用` 是本页最重要的链路，必须突出两种调用方式。
- 不要出现 `设备`、`文件`、`大模型密钥`。
- 不要出现 `子Agent`，避免页面复杂化。
- 不要出现具体业务系统、产品名、订单、调度、供应计划等业务词。

## Agent 调用应用的两种方式

在 `Agent -> 应用` 之间放两个并列的小卡片或胶囊标签，表达 Agent 调用应用的两种方式：

```text
人机API
拿用户Cookie调用

机机API
拿应用Token调用
```

标注方式：

- 两个标签必须放在 `Agent` 和 `应用` 之间，作为调用方式说明。
- `人机API` 和 `机机API` 是调用应用的两种方式，不要画成新的主体节点。
- `人机API` 的说明必须是：`拿用户Cookie调用`。
- `机机API` 的说明必须是：`拿应用Token调用`。
- 两个标签可以上下并列，也可以一上一下夹在主箭头附近，但不能让连线变乱。
- 标签必须是卡片式或胶囊式，背景色放在框内。

## 安全风险标注

在主图周围加入 4 个简洁风险标签，全部必须放在明确边界的卡片或警示框中：

```text
身份混淆
系统难区分人操作还是 Agent 代操作

凭据放大
Cookie / Token 让 Agent 获得过宽权限

审计断链
日志只记录调用，看不清任务意图

幻觉越权
错误推理触发工具调用，执行后不可逆
```

风险标签样式：

- 可以使用橙色或红橙色小型警示卡片，但颜色必须在卡片内部。
- 不要使用大段风险说明文字。
- 每个风险标签最多两行：第一行风险名，第二行一句短解释。
- `幻觉越权` 必须表达“AI 幻觉导致工具越权调用，且执行后不可逆”。
- 风险标签不要遮挡主链路、调用方式标签或节点。
- 风险卡片数量只保留这 4 个，不要额外增加风险点。

## 页面布局

采用上下结构：

```text
顶部：02 / 智能体模式 + 主标题 + 副标题
中部：用户 -> Agent -> 应用 -> API -> 数据库 主链路图
下部：结论带
```

顶部：

- 左上放小标题标识：`02 / 智能体模式`
- 主标题使用深蓝色大号粗体。
- 副标题使用深灰色中号文字，一行或两行以内。

中部：

- 主视觉是一条清晰横向链路。
- `用户` 在左侧，`Agent` 在中间偏左，`应用` 在中间偏右，`API` 和 `数据库` 在右侧。
- `Agent -> 应用` 之间放两张调用方式标签：`人机API` 和 `机机API`。
- 四个风险标签围绕主链路左右排布，保持留白。
- 连线数量要少，避免交叉。

下部：

增加一条结论带：

```text
执行主体被拆分 · 调用凭据被复用 · 授权与审计出现断点
```

结论带要简洁醒目，可以放在浅色长条或胶囊框中，但不要做成厚重卡片。

## 白底与框内颜色规则

必须严格执行：

- 整个画布背景是纯白色 `#FFFFFF`。
- 所有框框外部区域保持纯白色。
- 背景色、色块、渐变、警示色等颜色渲染只允许出现在框框内部、节点内部、标签内部、图标内部、箭头和边框上。
- 所有需要背景颜色渲染的地方，都必须有明确框框承载，可以是卡片式、胶囊式、节点式或其他合适风格，并且只在框框内部做背景颜色渲染。
- `Agent`、`应用`、`API`、`数据库`、调用方式标签、风险标签、结论带可以各自使用独立浅色或渐变填充。
- 不要使用外发光、重投影、玻璃拟态、背景光斑、渐变底板或整页色块。
- 如需阴影，只能非常轻微，不能让框框外的背景看起来变灰或有色。

## 视觉风格

- 背景：纯白色 `#FFFFFF`。
- 主色：蓝色、紫色、青色渐变，延续第一页和参考图 2。
- 风险色：橙色或红橙色，只用于风险标签内部。
- 文字：深蓝或深灰。
- 节点：现代圆角，优先无阴影，保持干净。
- 整体：科技感、企业汇报风、低信息噪音。

不要让页面变成说明书截图。图要像正式 PPT 中的抽象链路图，而不是系统设计文档截图。

- `Agent -> 应用` 之间包含两个调用方式标签：`人机API` 和 `机机API`。

- `幻觉越权` 明确表达：AI 幻觉会导致工具越权调用，且执行后不可逆。
- 图中没有具体业务词、厂商 Logo、供应计划、调度、订单等业务语义。
- 画布背景为纯白色，除框框内部、图标、箭头和边框外，其余区域没有任何底色。
