```text

必须通过合规 MCP、安全沙箱和 MCP 网关集中访问
```

第 5 页进入问题拆解二，聚焦凭证委托方式：


本页不是重新讲资源访问改造，而是把第 2 页中的 `Cookie / Token 让 Agent 获得过宽权限` 和第 4 页中的受控访问链路，落到第二项治理动作：Cookie 隔离与委托令牌转换。
