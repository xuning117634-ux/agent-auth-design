## 凭证与策略链路

请在页面中用短标签表达以下两条链路，但不要写成长段文字。

凭证转换链路：

```text
用户 Cookie -> TokenA -> TokenB -> 用户 Cookie
```

策略判定链路：

```text
用户访问Agent的权限策略判定
A2A调用权限策略判定
用户访问工具的权限策略判定
```

表达要求：
- `用户 Cookie` 出现在用户登录入口和 MCP 访问目标工具两段链路上。
- `TokenA` 出现在人机网关到 Agent A / Agent 中台、Agent A / Agent 中台到机机网关两段链路上。
- `TokenB` 出现在机机网关到 Agent B、Agent B 到 MCP 网关两段链路上。
- `Cookie -> TokenA` 放在 `Agent 网关（人机）` 附近。
- `TokenA -> TokenB` 放在 `Agent 网关（机机）` 附近。
- `TokenB -> 用户 Cookie` 放在 `MCP 网关` 附近。
- 三类策略判定从 `Agent 权限策略中心` 分别指向三类受控网关，不要合并成一个泛化“策略判定”标签。
