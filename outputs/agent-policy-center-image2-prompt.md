# Agent 权限策略中心极简架构图 image2 提示词

## 使用方式

把下面提示词复制到远端 ChatGPT，并上传参考图。目标是生成一页 16:9 PPT 架构图：极简、层次清楚、颜色有区分，不能像说明书截图。

## 可直接复制的提示词

请基于我上传的参考图，生成一页 16:9 中文企业架构 PPT 图。

标题：

```text
Agent 权限策略中心控制逻辑
```

这是一页领导汇报架构图。不要大段文字，不要说明书式卡片。请用“结构 + 箭头 + 小标签 + 图关系 + 编号流程”表达。

## 核心调整

- `策略决策` 内部采用左右两个并列子框：左侧 `图结构决策引擎`，右侧 `决策过程`。
- `图结构决策引擎` 不要占大面积，比例稍微小一点，刚好容纳节点关系即可。
- `解析 -> 图检索 -> 计算 -> 决策 -> 结果` 是决策区内部的小字流程提示。
- 左侧增加 `MCP 市场` 输入源，箭头标签为 `工具信息`。
- `Agent 注册与管理` 输入箭头标签为 `Agent 信息`。
- 中部大模块标题写 `策略决策`。
- 右侧流程标题写 `决策过程`，并且必须放在右侧流程框框内部。
- 必须补出类似参考图二的 `决策过程`，用编号步骤卡片表达。
- `ALLOW / AUTH_REQUIRED / MANUAL_REVIEW / DENY` 放在 `策略决策过程` 下方，不要放到右侧服务区中间。
- `Agent 注册与管理` 下方不要加任何说明文字。

## 总体布局

采用横向结构：

```text
左：Agent 注册与管理 / MCP 市场
中：Agent 权限策略中心
右：MCP 网关 / A2A 网关
```

左侧画两个输入框，上下排列。输入框内部只写模块名，不写说明：

```text
Agent 注册与管理

MCP 市场
```

两条输入箭头从左侧指向策略中心，箭头标签分别写在边上：

```text
Agent 注册与管理 -> 策略中心：Agent 信息
MCP 市场 -> 策略中心：工具信息
```

右侧两个调用方框纵向排列。服务框里只写服务名，不写说明文字：

```text
MCP 网关

A2A 网关
```

每个右侧调用方都有两条箭头：一条从调用方指向策略中心，表示请求策略决策；一条从策略中心返回调用方，表示返回决策结果。箭头标签写在边上，不要放进服务框内部。

请求箭头标签：

```text
Agent访问策略
A2A协同决策
```

返回箭头标签：

```text
决策结果
```

箭头标签位置建议：

```text
MCP 网关 -> 策略中心：Agent访问策略
策略中心 -> MCP 网关：决策结果
A2A 网关 -> 策略中心：A2A协同决策
策略中心 -> A2A 网关：决策结果
```

## 顶部角色

策略中心上方放三个角色卡片。每个卡片使用“角色名 + 策略项短语”的形式，文字要短，并和策略项对应。

图上写：

```text
Agent Owner
工具绑定
授权模式
工具白名单

Agent 行管
风险定级和管控

Agent User
工具委托授权
```

三个角色卡片使用不同浅色底：Owner 用浅蓝，行管用浅紫，User 用浅橙。角色卡片第二行开始只放名词短语，不加前缀词，不使用斜线符号。

角色下面的文字请做成细小的浅色标签或两行短标签，不要做成普通段落正文：

```text
Agent Owner：工具绑定、授权模式、工具白名单做成三个小标签
Agent 行管：风险定级和管控做成一个小标签
Agent User：工具委托授权做成一个小标签
```

三个角色各自用向下箭头连到策略中心里的对应策略项。

## 中央策略中心结构

中央大框标题：

```text
Agent 权限策略中心
```

内部只放三块，按上下布局：

```text
策略配置
策略决策
决策结果
```

### 1. 策略配置

放在策略中心上半部分。画成 5 个小卡片或胶囊标签，不要写解释。

```text
工具绑定
工具授权
授权模式
工具白名单
风险定级与管控
```

`工具绑定` 和 `工具授权` 必须上下并列，放在同一列中，形成一个上下组合。

附属小标签：

```text
授权模式：免授权 / 会话授权 / 每次授权
工具白名单：公开 / 指定用户
风险定级与管控：低 / 中 / 高
```

这些小标签必须小，不要撑大卡片。

### 2. 策略决策

放在策略中心中部，是视觉主模块，但不要让图关系图占满空间。

模块标题：

```text
策略决策
```

这个模块内部左右分栏，必须像参考图一那样画成两个并列子框。左侧是小型图结构引擎子框，右侧是编号决策流程子框。两个子框之间留一小段空隙，中间用一条实线箭头连接。

左侧子框，占策略决策宽度约 30%，高度和右侧子框对齐，但内容更简洁，节点关系图适度缩小：

```text
图结构决策引擎
```

这里画一个小型节点关系图，只保留 5 个节点：

```text
人
Agent A
Agent B
工具
会话
```

关系必须严格这样画：

```text
人 -> 工具
Agent A -> 工具
Agent A -> Agent B
会话 -> 工具
```

注意：

- `人` 和 `工具` 之间只能有一条线，方向为 `人 -> 工具`，标签是 `可访问`。
- 不要在 `人` 和 `工具` 之间画双向线或两条线。
- 不要把 `A2A` 画成节点。
- A2A 是 `Agent A -> Agent B` 这条边的关系标签。
- 不要把 `人` 和任何 Agent 节点相连。

连线标签只保留：

```text
可访问
绑定
A2A
授权
```

右侧子框，占策略决策宽度约 65%。必须画成一个带边框的子框，标题放在这个子框内部顶部，不要浮在外面。标题只写：

```text
决策过程
```

这里必须画成类似参考图二的编号步骤流程卡片，横向排列 5 步：

```text
1 策略解析
2 Agent-工具绑定校验
3 Tool 用户访问校验
4 授权模式判断
5 当前会话授权检查
```

在 5 个流程卡片上方或下方加一行小字：

```text
解析 -> 图检索 -> 计算 -> 决策 -> 结果
```

流程卡片必须全部放在 `决策过程` 子框内。流程卡片之间用箭头连接。

不要画虚线连接。请从左侧 `图结构决策引擎` 子框到右侧 `决策过程` 子框画一条清晰的实线箭头，箭头标签写：

```text
策略支撑
```

这条实线箭头表示：图结构决策引擎为决策过程提供策略支撑。

### 3. 决策结果

放在 `策略决策` 的正下方，而不是右侧网关中间。

画成横向四张状态卡：

```text
ALLOW
允许

AUTH_REQUIRED
需授权

MANUAL_REVIEW
需人工审核

DENY
拒绝
```

三态结果从 `策略决策` 向下输出。右侧 `MCP 网关` 和 `A2A 网关` 必须分别画两条箭头：请求箭头指向策略中心，返回箭头从策略中心指回网关。

右侧两个服务框内部只保留服务名。`Agent访问策略`、`A2A协同决策`、`决策结果` 必须作为箭头边上的标签出现，用来体现和策略中心的交互目的。不要增加第三个右侧服务框。

## 颜色与字体层级

不要整页只有一种蓝色。使用分层配色：

- 页面标题：深蓝，大号粗体。
- 策略中心主框：深蓝标题条 + 白色内容区。
- 策略配置：浅青或浅蓝底。
- 策略决策：浅紫或浅靛蓝底。
- 图结构决策引擎节点：多色区分，`人` 用青色，`Agent A` 和 `Agent B` 用绿色，`工具` 用橙色，`会话` 用金色；两个 Agent 之间的 `A2A` 边用紫色。
- 决策结果：`ALLOW` 绿色，`AUTH_REQUIRED` 橙色，`MANUAL_REVIEW` 紫色，`DENY` 红色。
- 右侧服务：浅蓝边框，不要和三态结果同色。

字体层级：

- 标题最大、最粗。
- `Agent 权限策略中心` 次大、粗体。
- `策略配置 / 策略决策 / 决策结果` 使用中等粗体。
- 其余小标签使用常规字重。
- 不要所有文字同样大小、同样粗细。

## 必须避免

- 不要大段文字。
- 不要说明书式长段落。
- 不要表格。
- 不要让图结构决策引擎占据策略中心大部分面积。
- 不要把三态结果放在右侧服务之间。
- 不要让 `决策过程` 标题浮在子框外面，它必须在右侧流程子框内。
- 不要把 `Agent访问策略`、`A2A协同决策`、`决策结果` 放进右侧服务框内部，它们必须放在箭头边上。
- 不要增加第三个右侧服务框。
- 不要给 `Agent 注册与管理` 或 `MCP 市场` 增加副标题或说明。
- 不要画与 Agent 本身访问范围相关的白名单或授权模块。
- 不要画 `人` 与任何 Agent 节点的连线。
- 不要把 `A2A` 画成节点，A2A 只能作为两个 Agent 之间的边标签。
- 不要在 `人` 和 `工具` 之间画两条线或双向线。
- 不要画从图结构决策引擎到决策过程的虚线，必须使用一条实线箭头。
- 不要把 `图结构决策引擎` 画得过大，它只占 `策略决策` 内部左侧约 30% 宽度。
- 三类角色下面只放名词短语，不加前缀词，不使用斜线符号。

## 验收标准

生成结果必须满足：

- 颜色有层次，不是单一蓝色。
- 字体有强弱，不是全图同一种字重。
- `图结构决策引擎` 是小型关系图，位于 `策略决策` 内部左侧。
- `策略决策` 内部是两个并列子框：左 `图结构决策引擎`，右 `决策过程`。
- 中部大模块标题是 `策略决策`。
- `决策过程` 是 5 个编号步骤，样式接近参考图二。
- `决策过程` 标题和 5 个编号步骤都在右侧流程子框内。
- 有小字 `解析 -> 图检索 -> 计算 -> 决策 -> 结果`。
- `图结构决策引擎` 到 `决策过程` 有一条实线箭头，标签为 `策略支撑`。
- `人` 只用一条线连接 `工具`，不连接任何 Agent 节点。
- 图中有两个 Agent 节点，A2A 是两个 Agent 之间的边标签。
- `决策结果` 在策略决策过程下方。
- `决策结果` 包含四态：`ALLOW`、`AUTH_REQUIRED`、`MANUAL_REVIEW`、`DENY`。
- 左侧有两个输入源：`Agent 注册与管理` 和 `MCP 市场`。
- `Agent 注册与管理` 到策略中心的箭头标签为 `Agent 信息`。
- `MCP 市场` 到策略中心的箭头标签为 `工具信息`。
- 右侧只保留 `MCP 网关` 和 `A2A 网关`。
- `MCP 网关` 到策略中心的请求箭头标签为 `Agent访问策略`，返回箭头标签为 `决策结果`。
- `A2A 网关` 到策略中心的请求箭头标签为 `A2A协同决策`，返回箭头标签为 `决策结果`。
- 左侧输入框下方没有任何说明文字。
