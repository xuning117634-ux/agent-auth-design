## 使用方式

把下面的提示词复制到图片/PPT 生成工具中，并上传两张参考图。

- 参考图 1：传统“人-机”模式复杂示意图，用来提取安全语义，不要复刻其复杂版式。
- 参考图 2：传统业务模式极简链路图，作为本页主图骨架。

目标是生成一页 16:9 中文企业汇报 PPT 图：简洁、现代、留白充足，重点讲清楚传统模式下“人直接访问应用，权限边界相对稳定”。

## 可直接复制的提示词

请基于我上传的两张参考图，生成一页 16:9 中文企业汇报 PPT 页面。

页面主题：

```text
传统业务模式：人直接访问应用，权限边界相对稳定
```

副标题：

```text
人在前台发起操作，软件按预设代码执行，系统可围绕“用户身份 + 角色权限 + 操作日志”建立控制。
```

重要要求：

- 保持原来的完整页面结构：顶部有小标题标识、主标题和副标题。
- 不要生成页脚、页码或多余装饰性顶部栏。
- 画布背景必须是纯白色 `#FFFFFF`。
- 除节点、标签、结论带和底部锚点这些“框框”内部之外，其余所有区域都必须保持纯白色。
- 不要使用整页浅灰、浅蓝、渐变、纹理、色块背景或大面积背景面板。

这是一页用来铺垫“智能体模式安全真空”的对比页。请以参考图 2 的极简横向链路为主图，不要照搬参考图 1 的复杂业务框图。参考图 1 只用于提取传统模式的安全假设：SSO 登录、身份认证、RBAC 授权、数据权限、固定代码执行、审计对象清晰。

## 核心图示

主图必须是横向链路：

```text
用户 -> 应用 -> API -> 数据库
```

要求：

- 保留参考图 2 的清爽风格：蓝紫渐变节点、细箭头、轻量图标、纯白背景。
- 去掉参考图 2 中任何具体业务名称，不出现具体系统名、产品名或业务名。
- 中间节点统一写成 `应用`，不要写具体业务。
- 不要把参考图 1 中的 `供应计划分析`、`供应计划`、`IDaaS` 等具体名称搬到图里。
- 主链路要放在页面视觉中心，节点间距均匀，箭头方向清楚。

## 安全标注融合方式

在主链路上方或靠近箭头的位置加入三组轻量标注，不要做成大卡片：

```text
用户 -> 应用：SSO 登录 / 身份认证
应用 -> API：RBAC 授权 / 接口权限
API -> 数据库：数据权限 / 资源边界
```

标注样式：

- 使用细线小标签或浅色胶囊标签。
- 标签靠近对应箭头，但不要遮挡主链路。
- 标签字号小于主节点文字。
- 标签颜色可以用浅蓝、浅紫、浅青区分，但整体保持统一。

主链路下方增加一条结论带：

```text
行为路径固定 · 权限判断前置 · 审计对象清晰
```

结论带要简洁醒目，可以放在浅色长条中，但不要做成厚重卡片。

## 页面布局

采用上下结构：

```text
顶部：标题 + 副标题
中部：用户 -> 应用 -> API -> 数据库 主链路图
下部：三条讲述锚点
```

顶部：

- 左上放小标题标识：`01 / 传统业务模式`
- 主标题使用深蓝色大号粗体。
- 副标题使用深灰色中号文字，一行或两行以内。

中部：

- 横向链路占据页面主要视觉区域。
- 用户节点使用人物图标。
- 应用节点使用蓝紫渐变圆角矩形。
- API 节点使用深蓝或蓝紫渐变圆角矩形。
- 数据库节点使用数据库圆柱图标或圆角数据库符号。
- 箭头使用细线，颜色为浅蓝灰。

下部：

放 3 个短句作为讲述锚点，横向排列：

```text
身份明确：系统知道是谁在操作
逻辑固定：应用按预设代码执行
边界稳定：权限围绕角色、资源、操作定义
```

三条锚点可以使用轻量分栏或简洁图标，不要使用厚重卡片墙。

## 白底与框内颜色规则

必须严格执行：

- 整个画布背景是纯白色 `#FFFFFF`。
- 所有框框外部区域保持纯白色。
- 背景色、色块、渐变等颜色渲染只允许出现在框框内部、节点内部、标签内部、图标内部、箭头和边框上。
- 所有需要背景颜色渲染的地方，都必须有明确框框承载，可以是卡片式、胶囊式、节点式或其他合适风格，并且只在框框内部做背景颜色渲染。
- `应用`、`API`、`数据库`、安全标签、结论带、底部锚点可以各自使用独立浅色或渐变填充。
- 不要使用外发光、重投影、玻璃拟态、背景光斑、渐变底板或整页色块。
- 如需阴影，只能非常轻微，不能让框框外的背景看起来变灰或有色。

## 视觉风格

- 背景：纯白色 `#FFFFFF`。
- 主色：蓝色、紫色、青色渐变，延续参考图 2。
- 文字：深蓝或深灰。
- 节点：现代圆角，优先无阴影，保持干净。
- 整体：科技感、企业汇报风、低信息噪音。

不要让页面变成说明书截图。图要像正式 PPT 中的抽象链路图，而不是系统设计文档截图。

- 图中有小标题标识、主标题和副标题，但没有页脚、页码或额外装饰性顶部栏。
